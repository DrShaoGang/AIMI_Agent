# AIMI

**Agentic Infrastructure for Metadata Intelligence**

AIMI is a three-year national implementation project that will develop a coordinated, human-governed multi-agent infrastructure for assessing, enriching, and validating metadata. Its goal is to help libraries and research repositories prepare digital collections for AI-enabled discovery, research, and service ecosystems.

The project is led by Purdue University Libraries and School of Information Studies in collaboration with the Purdue Rosen Center for Advanced Computing. It is supported by a $284,730 Institute of Museum and Library Services (IMLS) National Leadership Grant for Libraries.

## Why AIMI?

Modern repositories steward far more than traditional bibliographic records. They manage research datasets, software, computational notebooks, audiovisual material, digitized cultural heritage, and AI-generated content. Existing metadata automation is often rule-based, narrowly scoped, and difficult to apply across changing schemas and heterogeneous formats.

AIMI addresses this challenge with five interoperable agents:

1. **Readiness Agent** — assesses machine actionability, identifiers, schema conformance, vocabulary alignment, and provenance.
2. **Metadata Analysis Agent** — identifies structural gaps, missing fields, semantic ambiguity, and schema misalignment.
3. **Knowledge Retrieval Agent** — retrieves authoritative vocabularies, ontologies, and persistent identifiers.
4. **Metadata Enrichment Agent** — creates structured, standards-aligned metadata enhancements.
5. **Validation Agent** — checks consistency, accuracy, transformation quality, and schema compliance.

Governance spans the entire workflow through field-level permissions, confidence reporting, audit logs, decision traces, explanation views, and human review.

## Pilot environments

AIMI will be prototyped across four data ecosystems:

- Purdue University Research Repository
- Illinois Data Bank
- Amazon Web Services Open Data
- NASA Open Data

## Project status

This repository is at the documentation and project-foundation stage. Implementation code, evaluation materials, and technical guidance will be added as the project progresses.

## Intended outputs

- A functioning diagnostic-to-enhancement pipeline composed of five interoperable agents
- Metadata extension applications for selected repositories and digital collections
- An open-source AIMI framework, including source code, containers, and configuration documentation
- Readiness criteria, evaluation metrics, and validated workflows
- Governance guidance and a practical implementation guide
