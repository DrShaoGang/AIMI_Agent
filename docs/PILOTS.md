# Pilot Environments

AIMI will be evaluated in four environments representing two broad classes of metadata ecosystem. The diversity of these environments is central to testing transferability.

## Academic research-data repositories

### Purdue University Research Repository

The Purdue University Research Repository supports institutional research data and scholarly outputs. It provides an environment for testing repository-integrated readiness assessment and metadata enhancement.

### Illinois Data Bank

The Illinois Data Bank publishes and preserves research datasets across disciplines. It provides a second academic context for evaluating diagnostic, enrichment, and validation workflows.

## Public open scientific-data platforms

### Amazon Web Services Open Data

AWS Open Data represents large-scale public datasets delivered through cloud infrastructure. It provides an environment for examining metadata at platform scale and across varied domains.

### NASA Open Data

NASA Open Data provides scientific and mission data intended for broad discovery and reuse. It supplies a public-sector scientific context with diverse metadata requirements.

## Evaluation dimensions

Pilot evaluation is expected to consider:

- Metadata completeness
- Vocabulary and identifier alignment
- Schema conformance
- Reduction in ambiguity
- Computational usability
- Accuracy and consistency of generated enhancements
- Librarian interpretability and trust
- Workflow usability
- Transferability across collections and institutions

## Responsible use of pilot data

Dataset selection, access, processing, and reporting procedures will be documented as the pilots are designed. Repository policies and applicable data-governance requirements remain authoritative.
